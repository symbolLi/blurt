# PM 工作流：录屏口述 bug → 勾选导出飞书多维表格

给自己（PM）的操作手册。整条链路：对着产品录屏口述 → Blurt 转写成清单、每条配标注截图 →
客户端列表里勾选要报的 → 右键「导出到飞书」→ 表格多出几行（描述、严重程度、类型、提出人、截图全带）。
导出走 Blurt 自带的飞书直连（自建应用身份），电脑上不需要装 lark-cli、node 或任何别的东西。

## 一次性准备（飞书后台，约 10 分钟）

1. 打开 [open.feishu.cn](https://open.feishu.cn) → 创建企业自建应用（名字随意，比如「Blurt 导出」）。
2. 应用后台 → 权限管理，开通这两类权限：
   - 多维表格：读写（查看、评论、编辑、管理数据）
   - 云文档：上传、下载（导出截图要用）
3. 在飞书里打开目标多维表格（如「Bug 反馈清单」）→ 右上角分享 → 协作 → 添加应用，给它「可编辑」。
4. 应用后台 → 版本管理与发布 → 创建版本并发布（管理员审核通常很快；自建应用一般自己通过）。
5. 凭证与基础信息页里能看到 **App Key** 和 **App Secret**，留好。

## 绑定（每台电脑一次）

Blurt 客户端 → 设置 → **飞书**：

1. App Key、App Secret 粘贴进去（Secret 只存在本机 `~/.blurt/config.json`，权限 600，界面上不再回显；
   留空表示沿用已保存的那个）。
2. 表格链接：从飞书表格地址栏复制 **`/base/` 开头** 的完整链接（要带 `table=tbl…` 参数）。
   注意：从知识库里打开的表格地址是 `/wiki/` 开头，那种链接解析不了——到「我的空间」里找到这个表格本体再复制。
3. 提出人：填自己在飞书里的名字（导出的每行都会带；绑定时会按名字在飞书里精确找人，找不到会提示，
   不影响其余列导出）。
4. 点「绑定」。客户端会拿这组凭证实际访问一次表格验证（凭证错、权限缺、表格没共享给应用都会在这一步报
   中文提示），通过后写入本机配置——主窗口列表里的「导出到飞书」菜单随即出现。

## 日常导出

主窗口列表（可跨项目多选）→ 右键 / ⋯ 菜单 → 「导出到飞书」。刘海岛显示进度；成功、部分失败、
全部失败都有对应提示。每条一行：问题描述 = 条目标题，详细描述 = 清单里的一句话描述，截图逐张传到附件列。

## 已知限制

- 表格链接只认 `/base/` 直链，不认知识库 `/wiki/` 链接（见上）。
- 绑定只验证凭证和表格访问权，不预演附件上传；附件权限漏开的话，第一次导出才会暴露（提示里会说明）。
- 换电脑、换表格：设置 → 飞书里重新绑一次即可，旧的自动覆盖。

## 换一台电脑（公司电脑）迁移清单

1. clone 自己的 fork，按 README 装（`record.py build`）。
2. PM lens 模板：`skills/blurt/reference/lenses/pm.md` 复制到 `~/.blurt/lenses/pm.md`（本机这份模板即占位版，
   不含任何真实 token 和人名）。
3. 飞书后台的准备工作如上（应用和表格沿用即可，不用重建；换了飞书账号才要重新做一遍准备）。
4. 设置 → 飞书 → 绑定，然后正常用。
